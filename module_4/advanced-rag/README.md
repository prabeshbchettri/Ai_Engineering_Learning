# Advanced RAG System

A modular Retrieval-Augmented Generation application.

## Planned capabilities

- Document ingestion and intelligent chunking
- Embeddings and persistent vector storage
- Hybrid retrieval and reranking
- Query transformation and adaptive routing
- Structured-data retrieval
- Answers with citations and abstention
- Conversation memory
- RAG evaluation and security
- FastAPI backend and Streamlit frontend

## Development setup

1. Create and activate a Python virtual environment.
2. Install project dependencies from requirements.txt.
3. Configure local environment variables when needed.
4. Run tests before integrating new components.
